# オンラインゲームプラットフォーム 仕様書

## 1. プロジェクト概要
- **目的**: 個人利用・コミュニティ向けのオンラインボードゲームサイト
- **コンセプト**: オマージュを中心としたミニゲーム集（みんなでわいわい遊ぶ）
- **ターゲットデバイス**: 
    - **スマートフォン最優先** (Mobile First)
    - PC、タブレットでも完全動作
- **主要機能**: 
    - 認証（完全招待制）
    - ゲームロビー（QRコード共有）
    - 1台で遊べる「ローカルモード」
    - 離れて遊べる「オンラインモード」

## 2. 技術スタック構成
既存の `platform` ディレクトリの構成を踏襲・拡張します。

- **Frontend**: Next.js 15+ (App Router), Tailwind CSS v4
    - **UI**: スマホでの操作性を最優先（大きなボタン、タッチ操作最適化）
    - **Animation**: Framer Motion (リッチな演出)
- **Backend / Realtime**: Node.js + Socket.io (または Supabase Realtime)
    - リアルタイム性が重要（早押し判定など）
- **Database / Auth**: Supabase (PostgreSQL)
    - 認証、ユーザーデータ、招待コード管理

## 3. 機能要件

### A. 認証・ユーザー管理 (Authentication)
*   **完全招待制**:
    *   新規登録時に「招待コード」必須。
    *   **招待コード仕様**:
        *   **管理者 (Developer)**: `taiseipaisen@gmail.com` は**無制限**に招待可能。
        *   **一般ユーザー**: 1人につき**最大5人**まで招待可能。
*   **アカウント情報**:
    *   `username`: 表示名
    *   `avatar_url`: アイコン画像
    *   `id`: UUID (Supabase Auth連携)

### B. ロビーシステム (Lobby System)
*   **スマホ特化ロビー**:
    *   縦画面で見やすいルームリスト。
    *   URL/QRコードでのルーム招待。
*   **ルーム機能**:
    *   入室制限（パスワード）。
    *   観戦モード。

## 4. データベース設計 (Supabase)
`platform/supabase/schema.sql` をベースに、課金要素を除外して構築。

### Tables
1.  **users**
    *   `id` (UUID, PK): Supabase Auth連携
    *   `username` (TEXT): ユニーク
    *   `avatar_url` (TEXT)
    *   `invited_by` (UUID): 招待者
    *   `created_at`: 作成日
2.  **invitation_codes**
    *   `code` (TEXT, PK): 招待コード文字列
    *   `created_by` (UUID): 発行者
    *   `is_used` (BOOLEAN): 使用済みフラグ（個人利用なら回数制限なしコードもアリ）
    *   `used_by` (UUID): 使用者（1回切りの場合）

## 5. 収録ゲーム第1弾: 「My Mysterious Creatures」（ナンジャモンジャ風）

### コンセプト
謎の生物に名前を付け、再登場したらその名前を誰よりも早く叫ぶゲーム。

### 実装モード
#### A. ローカルモード（1台のスマホで遊ぶ）
*   **操作**: 1台のスマホを真ん中に置く。
*   **名前付け**: プレイヤーが口頭で宣言（入力不要）。
*   **回答**: 誰かがカードをタップしてめくる → 既出なら叫ぶ → 正解者がカード獲得（手動でポイント加算ボタンを押す）。

#### B. オンラインモード（それぞれの端末で遊ぶ）
*   **操作**: 各自の画面で操作。
*   **名前付け**: テキスト入力、またはマイク入力（Web Speech API）。
*   **回答（早押しシステム）**:
    1.  画面に「早押しボタン」が表示される。
    2.  既出キャラが出たらボタンを押す。
    3.  一番早かった人に「回答権」付与。
    4.  マイクで叫ぶ or テキスト入力 or （VC繋いでるなら）口頭で言って、親が「正解/不正解」判定。

## 6. UI/UX デザイン方針
*   **テーマ**: "Friendly & Pop"
    *   親しみやすい色使い。
    *   直感的な操作（説明書を読まなくても遊べる）。
*   **SP First Implementation**: PC画面はスマホ画面を中央に表示するようなスタイルでも可、あるいはレスポンシブに広げる。
